# アルデー

## サイト概要
### サイトテーマ
近所の穴場やちょっといい場所を住民同士で共有・記録し、時間があるときの外出のきっかけを見つけられるコミュニティサイトです。

### テーマを選んだ理由
予定のない休日や空き時間があっても行き先が思いつかず、結局自宅で過ごしてしまうことがよくありました。検索をすれば有名なスポットはすぐに見つかりますが、人気があるがゆえに混雑していたり、これまでに訪れたことのある場所であることが多く、日常に新しい変化を取り入れたいと思っても、その方法が見つからずにいました。

このような「ちょっといい場所」は、Googleマップや観光サイトで得られる情報とは異なり、地元の住民だからこそ知り得るものです。検索エンジンやレビューサイトのデータには蓄積されにくく、住民同士の共有によってしか広まらないという問題があります。また、自分で見つけた場所であっても、記録に残しておかなければ、どこであったかを忘れてしまいがちです。こうした記録の課題に対しては、投稿を通じて自分自身の発見を残せる仕組みで応えたいと考えました。

同様の課題は、子育て中で近隣の遊び場を探している方や、自身の生活圏に詳しくない方にも当てはまると考えました。

こうした「ちょっといい場所」を見つけて外出することが、いつもの日常に小さな変化を加え、その日を少し彩るきっかけになるのではないかと考えました。住民同士の共有と記録の両方を通じて、近所の“ちょっといい場所”を見つけられるサービスを実現したいという思いから、本テーマでポートフォリオを制作しようと考えました。

### ターゲットユーザ
- 予定のない休日や空き時間に、外出のきっかけを求めている方
- 子育て中で、近隣で気軽に利用できる遊び場を探している方
- 転居して間もない、または長く居住していても自身の生活圏に詳しくない方

### 主な利用シーン
- 特に予定のない休日に、近隣で気軽に立ち寄れる場所を探したい時
- 子どもと共に、混雑していない近隣の公園や遊び場を探したい時
- 散策中に見つけた場所を、自身の記録として残しておきたい時
- 転居先や旅行先で、観光情報誌には掲載されていない地元ならではのスポットを知りたい時

## 開発環境
- OS：Windows
- 言語：HTML, CSS, JavaScript, Ruby, SQL
- フレームワーク：Ruby on Rails
- データベース：SQLite（開発環境）
- IDE：Visual Studio Code（VSCode）

## 本番環境
- インフラ：AWS（EC2, ALB, Route53, Certificate Manager）
- Webサーバー：Nginx
- アプリケーションサーバー：Puma
- データベース：MySQL

## 主な使用技術
- 認証：Rails標準のhas_secure_password
- 画像処理：image_processing
- ページネーション：kaminari
- 位置情報：geocoder（Google Geocoding API）
- 地図表示：Google Maps JavaScript API
- 画像カルーセル：Swiper
- 評価UI：Raty.js

## 実装済み機能

### 投稿・記録
- 投稿の作成・編集・削除(タイトル、説明、カテゴリ、位置情報、複数枚の写真)
- タグ機能(自由入力の特徴タグ、選択式のおすすめ時間帯タグ)
- 「行きたい」「行ってみた」の記録、項目別評価
- 近所歴バッジ(居住年数に応じた表示、引っ越し後も過去の投稿には当時のバッジを表示)
- コメント機能(匿名投稿)

### 検索・発見
- キーワード・カテゴリ・タグによる検索
- 地図検索(現在地を中心とした半径指定での絞り込み)
- 「今日のアルデー」(居住地を考慮したおすすめ表示)

### グループ機能
- グループの作成・編集・削除
- グループへの参加・退会、オーナー権限の譲渡
- グループ限定投稿

### アカウント
- 会員登録・ログイン・ログアウト
- ゲストログイン(投稿・グループ参加などの操作は制限)
- プロフィール編集、退会(ステータス管理による論理削除)
- 他ユーザーのプロフィール閲覧(共通のグループに参加している場合のみ)

### 管理者機能
- ユーザー・投稿・コメント・グループの管理
- オーナー不在グループへの新オーナー指名

## 今後実装予定の機能
- 「行ってみた」記録（Visit）の編集・削除機能
- 投稿写真の追加アップロード機能（既存の写真を残したまま新しい写真を追加できるようにする）
- 投稿写真の一部差し替え機能（特定の1枚だけを選んで削除・差し替えできるようにする）
- コメントの通報・未確認タブによる管理機能
- 投稿の「思い出化」機能：建物が別のものに変わってしまった投稿を投稿者が地図・検索・一覧などの公開の場から外し、マイページのアルバムとしてのみ残せるようにする（コメントや「行ってみた」の記録は削除せず、訪問した人にとっても思い出として残る）。また、建物が変わっていることを誰でも報告できる機能もあわせて実装予定

## 使用素材
- テストデータ：Faker gemを使用し、氏名・自己紹介文・投稿の緯度経度などをランダムに生成しています
- 投稿画像：写真AC（https://www.photo-ac.com/）の画像を使用しています
